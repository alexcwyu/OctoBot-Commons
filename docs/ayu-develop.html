Design decisions

Decision Rationale Tradeoff Evidence
Separate user-owned and profile-owned configuration. Lets profiles override strategy settings while preserving global user preferences. Correct output depends on each Profile managed-element contract. Configuration._generate_config_from_user_config_and_profile (L118) / Configuration.save (L128)

Strengths and limits

Strengths

  • Shared profile merging and typed node primitives support consistent host/package representations. Configuration._generate_config_from_user_config_and_profile (L118) / BaseTree.set_node_at_path (L85)

Limitations

  • Trading/evaluator semantics belong to higher packages; this library cannot be compared as an independent trading engine. Configuration.read (L66) / SQLiteDatabase.initialize (L60)
